## ⚡ Tech Stack

- **Core Framework:** React 19 + TypeScript
- **Bundler & Tooling:** Vite 8
- **Styling & Design System:** Tailwind CSS, Glassmorphism, Custom Cyber Theme
- **Animations:** Framer Motion
- **Icons:** Lucide React & Custom SVG Social Icons
- **Deployment & Hosting:** Vercel (Optimized SPA rewrites, Edge CDN, immutable asset caching)

## 🚀 Running Locally

Ensure you have [Node.js](https://nodejs.org/) (v18+ recommended) installed.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/roqaiahanjum/my-portfolio.git
   cd my-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 🛠️ Building for Production

To create a production-optimized build in the `dist` directory:

```bash
npm run build
```

To preview the production build locally on a local server:

```bash
npm run preview
```

---

## 🌐 Deploying to Vercel

1. Push your repository to GitHub.
2. Sign in to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your portfolio repository:
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
4. Click **Deploy**.
5. Go to **Settings > Domains** to add your custom domain (e.g., `roqaiahanjum.dev` or `roqaiah.com`).
6. When attaching a custom domain (e.g., `roqaiah.dev`), update canonical and social meta tags in `index.html` and `README.md`.
